# Mi Portafolio Web 💼

¡Bienvenido a mi portafolio profesional como desarrollador web!

## 🌐 Ver en vivo
[https://walcantaradev.github.io](https://walcantaradev.github.io)

## ✨ Características
- 🌓 Modo oscuro/claro con persistencia
- 📱 Diseño responsive (móvil, tablet, escritorio)
- 🔍 Buscador y filtros de proyectos
- 🤖 Chatbot interactivo
- 📊 Estadísticas de GitHub en tiempo real
- 🎨 Animaciones y efectos visuales
- 📬 Formulario de contacto
- 🚀 Botón volver arriba

## 🛠️ Tecnologías usadas
- HTML5
- CSS3 (con variables CSS para temas)
- JavaScript (ES6+)
- Particles.js (fondo animado)
- Chart.js (gráficos)
- GitHub API
