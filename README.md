# Mi Portafolio Web 💼

¡Bienvenido a mi portafolio profesional como desarrollador web!

## 🌐 Ver en vivo
[https://walcantaradev.github.io](https://walcantaradev.github.io)

## ✨ Características
- 🌓 Modo oscuro/claro con persistencia
- 📱 Diseño responsive (móvil, tablet, escritorio)
- 🔍 Buscador y filtros de proyectos
- 🤖 Chatbot interactivo
- 📊 Estadísticas de GitHub en tiempo real
- 🎨 Animaciones y efectos visuales
- 📬 Formulario de contacto
- 🚀 Botón volver arriba

## 🛠️ Tecnologías usadas
- HTML5
- CSS3 (con variables CSS para temas)
- JavaScript (ES6+)
- Particles.js (fondo animado)
- Chart.js (gráficos)
- GitHub API

## 📂 Estructura del proyecto
mi-portafolio/
│
├── index.html          # Archivo principal
│
├── css/                # Estilos CSS
│   └── style.css       # Estilos principales (modo oscuro/claro)
│
├── js/                 # JavaScript
│   └── main.js         # Lógica completa (chatbot, filtros, etc.)
│
└── assets/             # Recursos estáticos
    └── cv.pdf          # Currículum para descargar


## 🚀 Cómo ejecutar localmente
1. Clona el repositorio
2. Abre `index.html` en tu navegador
